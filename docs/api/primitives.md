# Primitives

The distribution math as standalone pure JAX functions — for custom
likelihoods, vmapped parameter grids, and non-stationary fields where a
distribution object would be in the way. Organised per family (`gev_*`,
`gpd_*`, `gumbel_*`, `frechet_*`, `weibull_*`), plus non-stationary EVT
helpers and spatial utilities.
