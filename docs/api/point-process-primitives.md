# Point Processes — Primitives

Pure functions for every process family: intensities, cumulative intensities /
compensators, log-probabilities, samplers (inversion and thinning), predictive
counts, and diagnostics (time-rescaling residuals, KS statistics, Ripley's K).
Families cover homogeneous / inhomogeneous Poisson, renewal, Hawkes
(exponential and general kernels), and marked processes — each in temporal,
spatial, and spatiotemporal flavours where they exist.
